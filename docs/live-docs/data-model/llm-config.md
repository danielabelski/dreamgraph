# LLM Configuration

> Holds the configuration settings for the Large Language Model (LLM) used in the DreamGraph system. It defines parameters for model behavior and performance.

**Table:** `llm_config`  
**Storage:** json  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| model | string | The name of the language model being configured. |
| parameters | object | Parameters that define the model's behavior. |
