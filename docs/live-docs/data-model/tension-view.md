# Tension View

> Represents the current tensions or conflicts within the graph data, highlighting areas that may require attention or resolution. It is used for monitoring and improving system coherence.

**Table:** `tension_view`  
**Storage:** json  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| status | string | Current status of the tension (active, resolved, etc.). |
| details | array | Details of the tensions identified. |
