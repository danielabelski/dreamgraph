# Cognitive Tuning

> Holds parameters and configurations for tuning the cognitive processes within DreamGraph. This includes settings for various cognitive tasks and their execution.

**Table:** `cognitive_tuning`  
**Storage:** json  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| tuning_id | string | Unique identifier for the tuning configuration. |
| parameters | object | The parameters used for cognitive tuning. |
