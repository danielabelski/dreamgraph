# Graph Snapshot

> Represents a snapshot of the current state of the graph, including nodes and edges. It is used for visualizations and to provide a consistent view of the graph at a given point in time.

**Table:** `graph_snapshot`  
**Storage:** json  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| version | number | Version number of the snapshot. |
| nodes | array | List of nodes in the graph snapshot. |
