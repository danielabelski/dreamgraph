# Event Router

> Manages the routing of events within the DreamGraph system, ensuring that events are processed by the appropriate handlers. It is essential for maintaining system responsiveness and coherence.

**Table:** `event_router`  
**Storage:** memory  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique identifier for the event router. |
| routes | array | List of routes for event processing. |
