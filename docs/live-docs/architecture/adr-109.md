# ADR-109: Use Server-Side Rendering for UI Components

**Date:** 2026-05-03T12:26:30.056Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** dashboard_server, explorer_ui  

## Context

Need to improve initial load times and SEO for the application.

**Constraints:**
- Must support dynamic data
- Must be compatible with existing frameworks

## Decision

Server-side rendering for all UI components.

### Alternatives Considered

- **Client-side rendering** — Rejected: Slower initial load times.
- **Static site generation** — Rejected: Not suitable for dynamic content.

## Consequences

- Faster load times and better SEO.

**Risks accepted:**
- Increased server load during rendering.

## Guard Rails

> ⚠️ Do NOT switch to client-side rendering without a clear strategy.
