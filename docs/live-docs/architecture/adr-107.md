# ADR-107: Use Shared DataGrid Component for Tables

**Date:** 2026-05-03T12:26:30.015Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** explorer_ui, dashboard_context  

## Context

Need a consistent UI for displaying tabular data.

**Constraints:**
- Must support sorting and filtering
- Must be reusable across different parts of the application

## Decision

Shared DataGrid component for all data tables.

### Alternatives Considered

- **Custom table implementations** — Rejected: Inconsistent user experience.
- **Third-party table libraries** — Rejected: Dependency management issues.

## Consequences

- Consistent and efficient UI for data display.

**Risks accepted:**
- Potential for performance issues with large datasets.

## Guard Rails

> ⚠️ Do NOT modify the DataGrid component without consulting this ADR.
