# ADR-104: Adopt Microservices Architecture

**Date:** 2026-05-03T12:26:29.953Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** feature, workflow  

## Context

Need to improve scalability and maintainability of the application.

**Constraints:**
- Must support independent deployment
- Must allow for service isolation

## Decision

Microservices architecture for core components.

### Alternatives Considered

- **Monolithic architecture** — Rejected: Difficult to scale and maintain.
- **Serverless architecture** — Rejected: Higher latency for certain workflows.

## Consequences

- Easier to scale individual components.

**Risks accepted:**
- Increased complexity in service communication.

## Guard Rails

> ⚠️ Do NOT merge services without a clear strategy.
