# ADR-089: Data Storage Strategy

**Date:** 2026-04-29T19:00:59.309Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** instance, policy_profile, config  

## Context

To manage different types of data efficiently, ensuring optimal performance and scalability.

**Constraints:**
- Transactional data must be stored in SQLite
- Configuration data must be stored in JSON format

## Decision

Transactional data uses SQLite, configuration data uses JSON files.

### Alternatives Considered

- **Use a single database for all data** — Rejected: Complexity in managing different data types and performance issues.
- **Use NoSQL for all data** — Rejected: Lack of support for complex transactions.

## Consequences

- Improved data retrieval performance for transactional operations.
- Easier configuration management.

**Risks accepted:**
- Potential data consistency issues between different storage formats.

## Guard Rails

> ⚠️ Do NOT change the data storage strategy without reviewing this ADR.
