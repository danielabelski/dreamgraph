# ADR-105: Implement Webhook-based Integration

**Date:** 2026-05-03T12:26:29.974Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** api_integration_hub, event_router  

## Context

Need to efficiently integrate with external services.

**Constraints:**
- Must support asynchronous communication
- Must be easy to implement

## Decision

Webhook-based integration for external services.

### Alternatives Considered

- **Polling** — Rejected: Less efficient and increases load.
- **Direct API calls** — Rejected: Tight coupling with external services.

## Consequences

- Reduced latency and improved responsiveness.

**Risks accepted:**
- Webhook delivery failures could lead to data inconsistency.

## Guard Rails

> ⚠️ Do NOT change the integration method without consulting this ADR.
