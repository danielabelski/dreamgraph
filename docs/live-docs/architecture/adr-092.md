# ADR-092: Integration Pattern for External Services

**Date:** 2026-04-29T19:00:59.399Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** cognitive_engine, api_integration_hub  

## Context

To facilitate seamless communication with external services while maintaining system integrity.

**Constraints:**
- Webhook-based integration for asynchronous communication

## Decision

Webhook-based async integration with external services.

### Alternatives Considered

- **Polling** — Rejected: Inefficient and increases load on external services.
- **Direct API calls** — Rejected: Tight coupling with external services.

## Consequences

- Reduced latency in data processing.
- Improved responsiveness to external events.

**Risks accepted:**
- Webhook delivery failures could lead to missed events.

## Guard Rails

> ⚠️ Do NOT change the integration pattern without reviewing this ADR.
