# Auxiliary Entities

> Defines auxiliary entities used for testing and classification within the DreamGraph system. These entities help in validating the functionality of the system and ensuring robustness.

**Table:** `auxiliary_entities`  
**Storage:** memory  

## Fields

| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique identifier for the auxiliary entity. |
| type | string | Type of the auxiliary entity. |
| properties | object | Properties associated with the auxiliary entity. |
