# ADR-162: Slice 5 — Card schemaVersion is a numeric literal with append-only pure migration registry; missing migrators throw

**Date:** 2026-05-09T21:53:54.350Z  
**Status:** accepted  
**Decided by:** collaborative  
**Affected entities:** extensions/vscode/src/architect-v2/cards/types.ts, extensions/vscode/src/architect-v2/cards/migration.ts  

## Context

Cards will be persisted as DreamGraph entities (ADR-159). Without a versioning strategy, future schema changes silently break old persisted cards or force destructive migrations.

**Constraints:**
- schemaVersion is a numeric literal type, not `number`
- MIGRATIONS map is append-only
- Each migrator is pure (no I/O, no Date.now)
- Throwing on missing/future versions is mandatory — silent drops are forbidden

## Decision

Every card carries `schemaVersion: 1` as a numeric literal. Slice 5 ships v1 only. A MIGRATIONS map (number → migrator) registers one pure function per bump (`migrate_v{n}_to_v{n+1}`). `migrate(input)` walks from input.schemaVersion to current; missing migrator throws (never silently drops). Future-version inputs throw. Alternatives rejected: no version field (drift accumulates, breaking changes are invisible); semver string (overkill for an internal type, parsing overhead).

## Consequences

- Persisted cards remain readable across version bumps
- Schema bumps become a deliberate event with a recorded migrator
- Renderers can rely on the literal type for exhaustive checks

**Risks accepted:**
- Forgotten migrator on a bump throws on every card load — mitigated by the same-commit guard rail and Slice 7 verification
- Many small bumps could create a long migration chain — batch when possible

## Guard Rails

> ⚠️ Do NOT bump CARD_SCHEMA_VERSION without adding a migrator entry in the same commit

> ⚠️ Do NOT make migrators impure (no I/O, no Date.now, no random)

> ⚠️ Do NOT silently drop unrecognized fields; migrators must explicitly handle them

> ⚠️ Do NOT change the literal type to `number` — the literal is what makes exhaustive checks meaningful

> ⚠️ Do NOT allow downgrade migrators — forward-only
