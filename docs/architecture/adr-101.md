# ADR-101: Use JSON for Configuration Storage

**Date:** 2026-05-03T12:26:29.891Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** config, configuration  

## Context

Need a flexible and human-readable format for application configuration.

**Constraints:**
- Must support structured data
- Must be easily editable by developers

## Decision

JSON files for configuration storage.

### Alternatives Considered

- **YAML** — Rejected: Less common in the current tech stack.
- **XML** — Rejected: More verbose and less readable.

## Consequences

- Easier configuration management for developers.

**Risks accepted:**
- Potential for syntax errors in JSON.

## Guard Rails

> ⚠️ Do NOT change the configuration format without reviewing this ADR.
