# ADR-112: API Security

**Date:** 2026-05-03T12:46:03.858Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** api_routes, user_auth  

## Context

Need to secure API endpoints to prevent unauthorized access.

**Constraints:**
- All API routes must require authentication
- Use API keys for service-to-service communication

## Decision

API key authentication for all API routes.

### Alternatives Considered

- **OAuth2** — Rejected: Overhead for the current use case.
- **Basic Auth** — Rejected: Less secure than API keys.

## Consequences

- Enhanced security for API endpoints.

**Risks accepted:**
- API key leakage could lead to unauthorized access.

## Guard Rails

> ⚠️ Do NOT change the authentication method without reviewing this ADR.
