# ADR-103: Use PostgreSQL for Data Persistence

**Date:** 2026-05-03T12:26:29.933Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** datastore_primary, data_store  

## Context

Need a reliable and scalable solution for data storage.

**Constraints:**
- Must support complex queries
- Must handle concurrent access

## Decision

PostgreSQL as the primary data store.

### Alternatives Considered

- **MongoDB** — Rejected: Not suitable for relational data.
- **SQLite** — Rejected: Not suitable for concurrent access.

## Consequences

- Improved data integrity and query performance.

**Risks accepted:**
- Potential for increased operational complexity.

## Guard Rails

> ⚠️ Do NOT switch to a different database without a thorough evaluation.
