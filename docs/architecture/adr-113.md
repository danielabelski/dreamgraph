# ADR-113: Integration Pattern

**Date:** 2026-05-03T12:46:03.895Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** event_router, api_event_bridge  

## Context

Need to integrate with external services efficiently.

**Constraints:**
- Use webhooks for asynchronous communication
- Ensure all integrations are idempotent

## Decision

Webhook-based integration for external services.

### Alternatives Considered

- **Polling** — Rejected: Inefficient and increases latency.
- **Direct API calls** — Rejected: Tight coupling with external services.

## Consequences

- Reduced latency and improved responsiveness.

**Risks accepted:**
- Webhook delivery failures could lead to missed events.

## Guard Rails

> ⚠️ Do NOT change the integration pattern without reviewing this ADR.
