# ADR-111: Data Storage Strategy

**Date:** 2026-05-03T12:46:03.809Z  
**Status:** accepted  
**Decided by:** system  
**Affected entities:** data_store, configuration, datastore_primary  

## Context

Need to manage different types of data efficiently.

**Constraints:**
- Transactional data must be stored in PostgreSQL
- Configuration data must be stored in JSON format

## Decision

PostgreSQL for transactional data and JSON for configuration data.

### Alternatives Considered

- **SQLite** — Rejected: Not suitable for high concurrency and scalability.
- **NoSQL** — Rejected: Does not fit the structured nature of the data.

## Consequences

- Improved data integrity and performance.

**Risks accepted:**
- Potential complexity in managing multiple data storage solutions.

## Guard Rails

> ⚠️ Do NOT change the data storage strategy without reviewing this ADR.
