# Snapshot Compatibility Guard

> A version-gating mechanism that validates explorer snapshot payloads against an expected client version before graph data is accepted.. Intent: This concept should exist because snapshot retrieval is not a raw fetch; it enforces a compatibility contract and produces a dedicated failure mode when the UI and daemon drift apart.
